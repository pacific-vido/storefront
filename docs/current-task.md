# Границы текущей задачи

Сделан только frontend-каркас приватного видеосервиса на демоданных.

Внутри задачи:

- Next.js App Router, TypeScript strict, Tailwind CSS
- маршруты `/login`, `/rooms`, `/rooms/[roomId]`, `/rooms/[roomId]/videos/[videoId]`, `/settings`
- демо-репозиторий в памяти: комнаты, плейлисты, видео, приглашения и права
- симуляция загрузки, удаления, приглашения и отзыва доступа
- unit-тесты этих правил и проверки typecheck, lint, architecture, build
- упаковка этого демо для одного web-сервиса Railway: standalone-сборка и Dockerfile

Вне задачи, сюда не входит:

- Nest.js, PostgreSQL и деплой из этого репозитория командой агента
- настоящая авторизация, OAuth и проверка доступа на сервере
- загрузка, хранение и обработка реальных видео
- платежи, подписки, livestream, комментарии, рекомендации, админ-панель

Демоизменения живут в памяти браузера и пропадают после обновления страницы. Клиентские проверки не защищают данные.
