# Принятые решения

## Название

Рабочее имя продукта — Pacificvido. Оно задаётся только в `src/shared/config/index.ts` и не считается утверждённым брендом. Пакет называется `pacific-vido`.

## Референс

Страница https://app.athletesocean.com/home открылась как публичный маркетинговый сайт про тренировки, а не как кабинет после входа. Боковую навигацию, карточки и плеер из кабинета увидеть не удалось. Интерфейс собран по текстовому описанию и логотипу Pacificvido, без чужих знаков и контента.

## Слои

FSD lite: `app → widgets → features → entities → shared`. Общий demo-репозиторий лежит в `features/demo-repository`, потому что он использует модели всех сущностей. Экраны получают его через публичный `index.ts`. Соседние features не импортируют друг друга: диалоги принимают колбэки, а виджет их связывает.

`cacheComponents` из шаблона Next.js 16 выключен. Сессия и данные живут в браузере, и кэш серверных компонентов им не нужен.

## Доступ в демо

Репозиторий берёт текущего человека из своей сессии и не принимает отдельный `userId` с клиента. Это всё равно симуляция: в браузере нет границы доверия. Для production те же правила должен выполнять Nest.js на каждом запросе.

Несуществующая комната, чужая комната и видео из другой комнаты — разные ошибки. Для чужой комнаты ответ не содержит её названия и списка. Плейлист не имеет своих прав: кто видит комнату, видит её плейлисты; зритель их не меняет.

Комната по умолчанию закрытая. Публичная комната видна любому вошедшему в демо человеку и открывается только для просмотра, без членства. Чужие закрытые комнаты в профиль не попадают и по прямому id не открываются. Новые комнаты создаются закрытыми.

Главная `/` показывает готовые видео из чужих публичных комнат, новые сверху. Кроме Avery и Jordan в демо есть ещё три вымышленных автора с публичными роликами; войти можно только как Avery или Jordan. Свои ролики и неготовые записи туда не входят. Библиотека `/rooms` — свои комнаты, свои видео и комнаты, открытые приглашением. Профиль `/people/[userId]` одинаковый по адресу для себя и для другого человека: имя, почта и только публичные комнаты с готовыми видео. Приватное и приглашения остаются в библиотеке.

Повторное принятие приглашения не создаёт второго членства. Отзыв снимает доступ к комнате, видео и плейлистам. Старое приглашение после отзыва не принимается снова; владелец может выслать новое.

## Загрузка и плеер

Файл не отправляется и не сохраняется. Демо читает имя, размер и MIME-тип. Имя с `fail` заканчивается ошибкой; Retry проходит симуляцию заново и доходит до ready. Пока операция идёт, второй retry той же записи отклоняется.

Все готовые видео показывают один и тот же короткий ролик CC0 (flower) из интерактивных примеров MDN. Это не содержимое «загруженного» файла.

## Интерфейс

Кабинет светлый и тёмный. Переключатель темы стоит в шапке и сохраняет выбор в браузере. В той же шапке вошедший человек видит своё имя и переходит в профиль; до входа там подпись Not signed in. Цвета светлой темы взяты с публичного Vimeo, потому что https://vimeo.com/home без входа открывает Join: фон `#fafcfd`, текст `#0a0e12`, кнопка `#17d5ff` с тёмным текстом. Боковая колонка постоянная от 768px, на более узком экране её открывает кнопка Menu. Слово «Pacificvido» на исходном логотипе тёмно-синее на чёрном, поэтому в шапке стоит волна-знак и название текстом. Чёрный фон знака убран, сама волна остаётся насыщенной. В светлой теме подложка тёмно-серая, в тёмной — светло-серая. На ширине от 768px сайдбар плавно сжимается кнопкой, как в Notion. Выбор держится, пока не обновить страницу. На телефоне по-прежнему кнопка Menu. Закрытие диалога — крестик. Порядок плейлиста меняется кнопками Up и Down. Кнопки, поля, вкладки и диалоги — shadcn на Radix: панель диалога непрозрачная, поверх неё отдельный overlay. Логотип и пустое состояние остаются своими, у shadcn нет их аналога.

## Зависимости

Next.js 16.4, React 19.3, Tailwind CSS 4, Vitest 5, TypeScript 5. `@types/node` обновлён до 24, потому что локальный Node — 24, а Vitest 5 не принимает типы Node 20. `npm audit fix --force` не запускался: предложенный фикс откатывает `eslint-config-next` на 14.

## Railway

Пока только план. Позже web, API и PostgreSQL — отдельные сервисы. Переменные окружения задаются в Railway. Постоянные видео не должны зависеть от локального диска инстанса.
